## Part 1 · 录入 Agent 终端交互（HSBC 真实 transcript 逐屏）

> 模拟移动端 PWA 的对话式录入。每屏一个代码块，左边是助手，`>` 后是用户输入。

### 屏 1 · 开场

```
持仓条件录入助手

先从一只票开始：你现在持有的美股里随便说一只——
它是什么？你当初为什么买它？

> HSBC，因为按照年来看，它的股价表现稳健上升的形状
```

### 屏 2 · 抽取结果呈现（复述 + 疑点摆出）

助手先把用户原话结构化复述，同时把「需要你确认」的疑点摆到台面上，不替用户决定。

```
✓ 记下 HSBC。

我把你说的复述一遍，确认我没理解偏：

  买入逻辑（你的原话）：「按照年来看，它的股价表现稳健上升的形状」

⚠️ 我注意到两点，需要你拍：

  ❶ 「稳健上升的形状」是价格图形——我目前不接行情数据，
     没法每天自动盯这条。先记成「人工自查项」
     （每月提醒你自己看一眼年线），不进自动核对。
     你的原始理由我留着，不丢。

  ❷ 光有图形不够，我得知道你信的到底是什么——
     图形本身，还是图形背后的公司？这决定我以后每天替你盯什么。

继续追问 ↓
```

### 屏 3 · 可判定性追问

```
1. 你信的是图形本身，还是图形背后的公司？
   如果 HSBC 往后继续每年稳涨，你觉得主要靠什么撑着？
   比如：一直大手笔派息回购？亚洲业务在涨？利率环境？
   还是你说不上来，就是走势看着稳？

2. 什么情况出现，你会觉得「形状破了，当初的理由不成立」？
   说具体一点：是跌多少（比如从高点回撤 20%）？
   跌多久（比如连续两个季度往下）？
   还是发生某件事（比如突然砍派息）？

> 1、公司  2、无法确定，那得想想什么会让这家公司变得让人无法信任
```

### 屏 4 · 「无法确定」→ 候选菜单（选一次填两槽）

用户说不清破什么时，不逼用户从零想，给成对候选。

```
「信公司」+「说不上什么算破」——大多数人就卡在这。这一步我来给候选，你挑就行。

A. 你信的是什么？（可多选、可补充）
   A1 真金白银的股东回报：高分红 + 持续回购
   A2 亚洲业务（香港、内地）利润基本盘稳
   A3 资本充足，监管不找大麻烦
   A4 管理层战略清晰，重组聚焦见效

B. 破的条件（勾 1–5 条，每条我每天都能从公告里核对）
   B1 宣布削减或暂停派息
   B2 回购规模大幅缩水或叫停
   B3 核心资本充足率（CET1）跌破管理层自己定的目标线
   B4 信贷成本暴增（尤其跟中国商业地产相关的）
   B5 CEO / CFO 突然换人
   B6 监管开出大额罚单

A 选几项？B 勾哪几条？

> 1、A4  2、B6？
```

### 屏 5 · 疑点呈现（信的与勾的不对应 + 问号澄清）

助手把「你信 A4 却勾 B6」的不匹配摆出来，并说明默认怎么处理；同时澄清 B6 那个「？」。

```
抓到一件事：你信的是 A4（管理层战略），勾的却是 B6（监管罚单）——这两个不是一对。

默认处理（你可改）：

  破局条件分两层——
    ① A4 的「镜像条件」我替你补上（破 A4 会是什么事件）
    ② B6 放进每只持仓默认带的「通用红线」
       （罚单 / 高管突变 / 财报重述，不管战略多好都兜底）

  B6 那个问号我也看到了——意思是：
    如果 HSBC 被监管开出大额罚单（比如当年 19 亿美元级别的洗钱罚单），
    不管战略多好，信任都清零。为让机器能核对，定成可判定的：
    单次罚款 ≥ 5000 万美元，可改。

每条条件我都配一个真实历史事件示例，帮你确认「击中时长什么样」：
  ① 战略转向 → 示例：〔待补一手来源〕（先把条件结构定下来，示例随后从 SEC/新闻补一手）
  ② CEO/CFO 离职 → 示例：〔待补一手来源〕
  ③ 监管大额罚单 → 示例：〔待补一手来源〕
```

### 屏 6 · 图形型 → 人工自查项的明示（落进确认卡前）

把屏 2 的 ❶ 兑现成卡片里的一个明确栏目，让用户看到「原始理由有安放处」。

```
关于你最初说的「形状」：

  这条是价格条件，系统不接行情，每天没法自动盯。
  我把它记成「人工自查项」——每月 1 号提醒你自己看一眼年线。
  它不进自动核对 loop，但不会从你的卡里消失。
```

### 屏 7 · 落盘前的确认卡

把整张卡结构化回述，用户「确认」后才入库（不确认只是 draft）。

```
确认卡 · HSBC（汇丰控股）

┌─ 买入逻辑（你的原话）───────────────────────────┐
│ 年线看股价稳健上升（图形）                         │
├─ 关键假设 ──────────────────────────────────────┤
│ A4 管理层战略清晰，重组聚焦见效                   │
├─ 破局条件（两层）────────────────────────────────┤
│ ① 镜像（系统补）宣布战略转向、重组叫停，或亚洲核心资产被剥离 │
│ ② 镜像（系统补）CEO / CFO 突然离职                │
│ ③ 通用红线（你勾）监管大额罚单，单次 ≥ 5000 万美元（可调）   │
├─ 人工自查项（每月提醒，系统不接行情）──────────────┤
│ • 价格「形状」：每月 1 号看一眼年线                │
├─ 下次裁判日（不等于「下次复盘日」）────────────────┤
│ 事件：2026-08-04 中报（下一次有新证据能证伪 thesis 的时点） │
├─ 录入估值锚 ────────────────────────────────────┤
│ 锚类型：P/TBV（银行股第一性原理）   值：1.3x（可改）   │
├─ 仓位上限档（规则查表，非 LLM 抽）────────────────┤
│ 软（HSBC：turnaround/深度价值，上限 ~10%）         │
└─────────────────────────────────────────────────┘

每天扫 HSBC 的 SEC 申报（6-K / 20-F）和头条新闻，命中任何一条就邮件推送，附原文链接。
判断权在你。改哪条？还是「确认」？

> 确认。大多数情况下不会触发对吗
```

### 屏 8 · 静默日设计说明 + 落盘

```
✓ 已落库（HSBC · status=有 thesis）

对，这正是设计意图。破局条件按定义是「小概率、高重要性」事件——
三天两头触发说明条件定错了。但没触发不等于没消息：

  • 命中条件 → 当天单独发邮件，写明命中哪条，附公告原文链接
  • 没命中 → 不单独打扰，每日简报一行带过：
           「已检查 N 只 / 0 触发 / 最近一个裁判日：HSBC 的 2026-08-04 中报」
    （这一行不能空——你要能从它确认系统活着，而不是猜）

下跌难受的日子，你要的就是那行「均未触发」——
坏的是价格，不是当初的理由。判断始终是你的。
```
