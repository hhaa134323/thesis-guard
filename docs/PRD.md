## 1. 一句话定位

用户用自然对话告诉 AI「我为什么持有这只票」，AI 追问并把破局条件整理成确认卡；之后每天由核对 Agent 用一手公开披露自动核对这些条件。命中当天单独发邮件，未命中合并进每日简报。**判断权永远归用户。**

## 2. 项目目的（双层）

- **用户层**：让自主决策的个人投资者以每天 1 分钟的时间成本完成持仓逻辑体检。
- **建设者层**：作为从 0 到 1 的 Agent harness 项目，核心交付是 harness 本身、双层 eval 与 error analysis 闭环。

## 3. 核心场景

### S1 对话式录入
- 用户自然对话说明持有理由。
- AI 必须追问（可判定性引导），把破局条件编译成结构化 thesis 卡。
- 经用户复述确认后入库。
- 用户表示「无法确定」时给出候选菜单（假设与其镜像条件），选一次填两槽；每条条件附一个真实历史事件示例。
- 用户原始理由若是价格图形型 → 记为「人工自查项」，每月提醒自查。

### S2 每日核对
- 核对 Agent 用 SEC EDGAR（按申报方类型路由，外国发行人以 6-K 为主）+ 公开新闻标题 RSS 核对每条破局条件。
- 输出状态机卡片：未触发 / 需关注 / 已触发，附证据与一手链接。

### S3 触达
- 命中条件当天单独发邮件。
- 未命中合并进每日简报，一行带过，不单独打扰。

### S4 收尾（用户动作）
- 「已触发」必须用户动作收尾：确认破了 / 标记误报 / 忽略。
- 误报与确认数据自动沉淀为 eval 标注。

### S5 人工自查项
- 价格图形型理由 → 每月提醒自查（系统不接行情）。

## 4. 非目标（Non-goals）

- 不给买卖建议、不推荐标的、不做仓位建议。
- 不预测涨跌、不输出目标价、不承诺收益。
- 不接入券商账户、不读取真实持仓、不代客操作。
- v1 不含价格类警报。
- v1 锁美股，不做 A 股 / 港股。
- 不做注册系统（5 人 beta 预置账号）。
- 不上应用商店、不提交小程序审核。
- 不做付费功能（LLM 成本作者自担）。
- 不写入用户 Notion 工作区。

## 6. 技术与分发约束

- PWA，移动端优先；不上应用商店，不提交小程序审核。
- 数据源仅限 SEC EDGAR 官方接口和公开新闻标题 RSS。
- 按申报方类型路由披露表单：外国发行人（20-F/6-K 申报方）以 6-K 为主渠道，不得沿用美国本土公司的「6-K 降级」规则。
- 不使用任何需要商业授权的行情数据；v1 不含价格类警报。
- v1 锁美股，不做 A 股/港股。
- 触达仅邮件；PWA 推送留到 v2。
- 后端从简：预置账号、仅邮件触达、单数据库。

## 9. 里程碑（4 周，每周约 10 小时）

| 周 | 目标 | 验收 |
|----|------|------|
| W1 | 对话录入跑通：聊 3 分钟生成一张 thesis 确认卡（含可判定性追问 + 复述确认） | 对话抽取一致率 eval ≥ 85% |
| W2 | 核对 Agent 上线：工具循环 + 证据自检 + 拒判 | 事件×条件判定一致率 eval ≥ 80% |
| W3 | 招募 5 个外部用户（熟人 + 社区混合；招募前补命名和一页纸 pitch），加埋点，观察首次录入卡点 | 专项观察：破条件自发 vs 菜单挑选比例 |
| W4 | 基于反馈做一次有取舍的迭代 | KILL 判据体检：7 天打开 <5 天，或没有一次影响过用户决策 → 停掉不养老 |
