> 页面层级：父页面「Skills 库」／祖父页面「AI 学习工作台」。
> 本仓库用途：核对 Agent 系统提示词的起点（三态、噪音过滤表、触发式深挖、轮值深挖、硬红线、回写规则）。本页是 Notion 活库的同名复查 Skill 原文快照，本仓库只读、不回写。

> 🧭 caca 拿到简报说「分析是否颠覆 thesis」就跑本流程：读简报 + 读台账（**含复盘备注**）→ 过滤噪音 → 判**三态**（破 / 逼近 / 未动）→ 逼近 / 已破候选烧 token 追一手 + 交叉验证 → 输出 4 判决 + 🔭观察项连续性 → durable 项自动回写台账。本页取代旧版「简报解读（价值视角 v2）」。

## 什么时候跑（不需要口令）
听到这类**意图**就跑：
- 「分析是否颠覆 thesis」/「分析 thesis」/「thesis 有没有破」
- 「解读简报」/「看下简报」/「看下持仓」
- caca 正在看某份简报页且问 thesis 相关 → 直接对那份跑

caca 指定日期（「昨天的」/「5/27 的」）→ 用 Briefing Date 精确过滤，其余不变。

## 本质（先内化）
每天只回答一个问题：**今天有没有新信息，真踩中某持仓写好的「破的条件」？** 默认答案「没有」。skill 的价值 = 让 caca 5 秒拿到可信的 No/Yes，并把稀有的 Yes、和「还没破但要盯」的事，变成**明天还记得的记忆**。默认 HOLD，CUT / ADD 是稀有事件。

## 节奏：日频 ≠ thesis 测试（v4 第一刀）

> ⏱️ **破的条件全是「连续多季 / 结构性 / 长期」，而日频输入只有一天的新闻 + 偶发文件——用日频信息去证伪季频命题，数学上注定证伪不了。** 所以日频跑出来的 HOLD 不是「我把 thesis 重测过、它扛住了」，只是「今天没有信息够得着我故意设得极高的门槛」。两者长得一样、差很远。别再让日频 HOLD 假装成测过了。

**日频（每天喊「解读简报」时跑）只合法做两件事 + 一件轮值：**
- ① 抓**离散证伪事件**：持仓相关 8-K / 财报 / 监管动作 / Alert: thesis_invalidated——这类一旦出现，当天就能命中破的条件。
- ② 扫**价值线**：逐只比对台账「加仓价 / 安全边际」，跌穿才出 ADD。
- ③ **轮值深挖 1 只**（见 ③.6）——日频唯一的「主动测试」，给 HOLD 挣饭票。
- 其余日频结构上只能是 HOLD / 观察项延续，不展开、不假装在测。

**真 thesis 测试 = 季频**：放在每只持仓的**财报日 / 下次复盘日**做，那天才逐条对破的条件、重算价值线、清理观察项。日频负责「别错过离散事件」，季频负责「系统性重测 thesis」——分工，不混为一谈。

## 三态（v3 核心 · 比旧版多一态）

| 状态 | 含义 | 去向 |
|---|---|---|
| 🔴 已破 | 命中「破的条件」原文 | CUT 候选 + 回写台账 |
| 🔭 逼近 | 某事实落进破的条件的*类别*，但未达标 | 观察项：不出判决，回写台账盯住——**必须带毕业线**（见 ③ + 硬红线） |
| 🟢 未动 | 没踩任何破的条件 | HOLD，不回写 |

## 4 判决（输出只能是这 4 种）

| 判决 | 何时 | 占比 |
|---|---|---|
| 🟢 HOLD | 默认。thesis 未变，无论涨跌 | ≥ 80% |
| 🔵 ADD | thesis 未变 + 现价跌破 caca 预先写好的价值线（台账「加仓价 / 安全边际」）；没写线的持仓不报 ADD | < 5% · 稀有 |
| 🔴 CUT | thesis 破（命中破的条件） | < 5% · 稀有 |
| ⚪ PASS | 该 ticker Status=待补 / 台账无此行 | 看写 thesis 进度 |

**🔭 观察项不是判决**——它是 context，绝不作为第 5 种判决（「密切关注」之类）喊给 caca。

## 价值线 = ADD 的唯一依据（巴菲特版）
ADD 不看「跌了多少」，只看「比价值便宜多少」。每只持仓的价值线由 caca **预先写在台账「加仓价 / 安全边际」**——功课在平静时做完，真跌时只照线执行，不临场拍脑袋。

- **方法配生意**：① 干净现金流的生意（MCO / FDS 类）用 owner-earnings 收益率或 reverse DCF；② 控股 / 投资型（BRK.B 类）用巴菲特两栏法，即每股投资额 + 给运营生意一个倍数；③ 指数 ETF（QQQ 类）不设单股价值线，用盈利收益率 vs 长债，或干脆定投。
- **线可写成算法**，每次复查按最新一手财报重算，不写死价格（范本见 BRK.B 那行）。
- **没写线 = 不报 ADD**：宁可漏一次加仓，也不靠「感觉便宜」错报；字段空就默认 HOLD。
- **VIX 飙升 / 宏观恐慌不是 ADD**，只是「把价值线清单逐只看一遍」的提示，真跌穿某只的线才出 ADD。
- **上限封顶（仓位 = thesis 脆弱度函数）**：ADD / 集中度还要过这一关——单一持仓上限不一刀切，按「thesis 越脆、上限越低」分档；某只已到它档的上限，再便宜也不加。判定看 thesis 破的条件有多难触发、信号有多难造假，**不看现在便宜不便宜**。代码层 position_concentration 已降为 info 只报事实 + 50% 兜底，不再替我下判决。档位 v1 可调：

| 档 | 上限 | 判据 | 现持仓 |
|---|---|---|---|
| 硬 thesis | 约 40% | 结构性慢变量；破的条件需数年加多重确认、证伪信号离散可观测 | FDS、BRK.B、MCO |
| 中 | 约 25% | 优质复利机但含中速变量，2-3 年可能被打脸 | VEEV、GOOGL、NOW、NFLX |
| 软 | 约 10% | turnaround / 深度价值 / 单点逻辑，错了快 | FIS、HSBC |
| 宽基 ETF | 约 50% | 无需 single-name thesis，作底仓或现金替代 | QQQ |
| trinket | 只减不加 | 1 股探针仓，无完整 thesis | CGNX、NVDA |

FDS 现 41.5% 是硬档顶格的主动高信念仓，不是破红线。数字 v1 可调，用着别扭直接改，判据骨架不动。

## 破的条件升级模板（量化滞后线 + 领先代理 · 逐只补功课）
旧破的条件多是「滞后 + 模糊词」（「明显蚕食」「连续多季」），等确认时 CUT 已晚、且给 AI 和稀泥的空间。逐只按下表升级（NVDA 已是范本）：

| 维度 | 怎么写 | 例（NVDA） |
|---|---|---|
| ① 量化滞后线（确认用） | 把模糊词翻成「具体数字 + 期数 + 一手出处」，消掉 AI 的弹性空间 | GAAP 毛利率跌破 70%（一手：10-Q） |
| ② 领先代理指标（预警用） | 配一个比公司自认更早露头的前瞻信号，进 🔭 观察项毕业线、不进判决 | 盯 Broadcom / AMD 季度指引 + TPU / Trainium 大客户中标，而非只等 NVDA 自认份额流失 |

每只持仓至少补两条：**1 条量化滞后线**（确认用）＋ **1 条领先代理**（日频 / 月频能露头、预警用）。补完台账「Thesis 破的条件」字段才真有牙齿。

## 流程

### ① 双查询并行 + 读简报正文
并行 2 个 `connections.notion.querySql`：
1. **简报库**（[📊 Pre-Market Briefing · 开盘前简报](https://app.notion.com/p/a2ecda8337a94475bb1b0f01a4ff3fe6)）：按 `"date:Briefing Date:start"` DESC、`"date:Generated At:start"` DESC 取 LIMIT 1，至少 SELECT `url`。caca 指定日期 → 改 `"date:Briefing Date:start" = ?`。
2. **持仓 Thesis 台账**（[🧭 持仓 Thesis · 价值投资台账](https://app.notion.com/p/565f32b20ad741c7b42d6eb07de5d0d4)）：全表，SELECT 必须含 `url, Ticker, Status, 持仓周期, "Thesis · 为什么买", "Thesis 破的条件", "加仓价 / 安全边际", "复盘备注", "date:下次复盘日:start"`。⚠️ **「复盘备注」必须 SELECT**——旧版 v2 漏了它，导致回写的判断 / 观察项第二天读不回来（死档）。v3 的记忆闭环全靠这一列。

拿到简报 url → `connections.notion.loadPage` 读正文。

### ② 噪音过滤（先砍掉 80%）

| 信号 | 处理 |
|---|---|
| 浮盈 / 浮盈未保护 / 1d-1w 涨跌幅 | 🗑️ 全丢，价值投资不看短期价格 |
| Form 4 M 码（RSU 归属）/ 单日 1 份 / 单日 ≥2 份全 M 码 | 🗑️ 丢，机械归属 |
| 8-K 小事项（投资展 / ESG / 品牌更新） | 🗑️ 丢 |
| 1-股 trinket 持仓 | 🗑️ 降级，不每日盯 |
| 杠杆 ETN / ETF（如 GDXU） | ⚠️ 永久 CUT 候选（结构性 decay） |
| VIX spike / 宏观恐慌 | 🔄 不直接报 ADD；翻面为「去看一眼价值线清单」——逐只比对台账价值线，只有真跌穿某只的线才出 ADD |
| 持仓股财报日（earnings_today） | ✅ 保留，季报 = thesis 检验时刻 |
| 持仓股 8-K 涉商业模式 / 客户 / 高管离职 / 竞争格局 | ✅ 保留，moat 触发器 |
| Form 4 S 码且金额 > 高管年薪 50% | ✅ 保留，真信号 |
| Alert: thesis_invalidated | ✅ 最高优先保留 |

### ③ 判三态 + 用复盘备注做连续性
对每只**仍有信号**的持仓：
1. **先读它的「复盘备注」**：① 这条信号我之前判过没？判过别重嚼；② 有没有相关的 🔭 观察项？看它较上次恶化 / 解除没。
2. 再 match 破的条件 → 三态 → 判决：

```javascript
for ticker T in 受信号影响的持仓:
    row  = 台账 WHERE Ticker = T
    note = row.复盘备注   // 连续性：判过没 / 有无相关 🔭 观察项

    if row 不存在 or row.Status == "待补":
        → ⚪ PASS(T) + 追问「你买 T 的 thesis？moat？什么情况卖？」

    elif row.Status == "有 thesis":
        if 信号命中 row.破的条件:
            → 🔴 CUT(T) + 引破的条件原文 + 「建议下一交易日清仓」
        elif 信号落进破的条件的"类别"但未达标:
            毕业线 = 写死「踩到什么具体指标 → 升 🔴 CUT」
            if 写不出毕业线:
                → 当噪音丢掉 或 直接出判决；不准立成「我在盯」的空观察项
            else:
                → 🔭 观察项(T)：记"盯什么 + 关联哪条破的条件 + 毕业线"，不出判决
        elif row.加仓价/安全边际 非空 且 现价 < 该线:
            → 🔵 ADD(T) + 引价值线原文（线可写成算法，按最新一手财报重算）
        else:
            → 🟢 HOLD(T)

    elif row.Status == "Thesis 已破":
        → 🔴 CUT(T) + 「你已标 thesis 破，何时清仓？」

    elif row.Status == "已清仓":
        从结果剔除
```

**绝对约束**：判决不给股数 / 价位 / 时点，只给判决类型 + 触发原因。caca 自己决定怎么执行。

### ③.5 触发式深挖关（boil the ocean · 仅逼近/已破候选）

> 🔥 **只对 🔭 逼近 / 🔴 已破候选跑这一关，🟢 HOLD 一律跳过。** thesis 复查是整套系统里错误成本最高、最不可逆的决定（砍不砍）——只有当某信号真的落进某持仓破的条件的*类别*时，才值得为这一件事烧 token 把它 boil 干。平时维持 5 秒、便宜。

出判决前，对每个 🔭 逼近 / 🔴 已破候选持仓依次跑：
1. **追一手**（别靠 Yahoo 标题定生死）：拉该事件的一手文件——8-K 正文 / `EX-99.1` / 10-Q（外国发行人看 6-K / 20-F）。走下方「核数子流程」。简报那条信号若没带一手链接，先去 SEC EDGAR 检索补齐。
2. **交叉独立来源**：就**这一条破的条件**交叉 ≥3 个**互相独立**的来源（一手文件 + 独立报道 / 分析，剔掉互相转载的），用 `connections.web.search` / `web.loadPage` 读到能下判断为止。
3. **分歧当信号**：输出两栏——**共识** / **分歧点（各方证据）**——别只给一个被抹平的结论；多来源都在复读同一通稿时，标「⚠️ 回音室，等同单源」。
4. **敏感度检点**：明说判决靠哪个来源支撑——「撤掉哪个来源，结论会从 CUT 翻回 HOLD」。

```javascript
for T in 逼近/已破候选:
    一手 = 拉一手文件(T 的触发事件)        // 没有一手链接 → 先去 EDGAR 检索
    源  = 交叉(T 的破的条件, n≥3, 独立)     // 去转载、去同源
    if 源 全部同源/转载:
        标「⚠️ 回音室」→ 当单源处理
    判决 = match(一手 + 源, T 的破的条件)
    if 判决 == CUT 且 仅 1 个独立来源支撑:
        → 降为 🔭 观察项（不出 CUT）+ 注明「待第二个独立来源确认」
    else:
        → 回到 ③ 的三态正常出判决
```

**回写**：深挖出的 🔴 CUT / 🔭 观察项，按 ⑤ 回写台账时带上**深挖结论 + 敏感来源**，供明天连续性复用。

**边界（别越界成反面典型）**：
- ❌ 不对 🟢 HOLD 持仓跑深挖——每天均匀烧 token = 回音室 + 虚假完整感 + 烧钱
- ❌ 不拿来源**数量**当指标——要的是**独立性 + 分歧可见**，20 个转载同一通稿等于 0
- ❌ 不新增第 5 种判决——这一关只加判决前的**验证深度**，结果仍落进 HOLD / ADD / CUT / PASS

### ③.6 轮值深挖（v4 第二刀 · 让 HOLD 挣饭票）

> 🔁 日频别再 12 只全瞥一遍就过。**每天强制挑 1 只**做反方辩护，12 只轮着来、约两周一圈——结论还是 HOLD 没关系，那个**证伪尝试**本身才是工作。这是日频唯一的主动测试，区别于 ③.5（只对逼近 / 已破候选触发）。

- **选谁**：按台账顺序轮值（或挑最久没被深挖的那只）；当天若已有 ③.5 触发的逼近 / 已破候选，**优先深挖候选**，轮值名额顺延。
- **举证责任反转（默认它正在破）**：深挖时默认假设「T 的 thesis 正在破」，我必须**主动证明它没破**——证不出「没破」才 HOLD。禁止用「默认 HOLD、再找证据维持」的姿势跑，那是确认偏误的温床。
- **怎么做**：对选中的 T 强制问一句——「**如果现在逼我论证 T 的 thesis 正在破，我最强的 case 是什么？**」再认真找这条 case 的证据，**强制走核数子流程拉一手**（即使结论会是 HOLD 也拉，不只信简报喂的 Yahoo 标题）；交叉源**查独立性不查数量**，全是转载就标「⚠️ 回音室＝单源」；判它够不够格触发破的条件。
- **出口（反证留痕 + 敏感度）**：① 真触发 → 升 ③.5 正常出判决；② 没触发 → 仍 HOLD，但输出那行必须含三项：**最强空头 case（带一手源）** ＋ **为何不够格（对哪条破的条件、差在哪个具体数字）** ＋ **翻空敏感点（撤掉哪条证据 → 结论翻成 CUT）**，证明今天真测过一只、且漏判可事后审计。
- **边界**：一天只深挖 1 只（候选另算），不均匀烧 token；轮值是给 HOLD 装牙齿，不是天天 boil the ocean。

### ⑤ 回写台账（durable 项自动写 · 纯 HOLD 不写）
**自动**回写（不必先问 caca，但写完在 chat 用编辑卡告知）的 durable 只有三类：

| 类型 | 触发 | 写什么 |
|---|---|---|
| 🔴 CUT / thesis 已破 | 命中破的条件 | 判决 + 破的条件原文 + 一手源 |
| 🔬 财报核数 | 持仓财报日核过一手数字 | 关键数字 + 对破的条件的结论 |
| 🔭 观察项变化 | 新增 / 恶化 / 解除 | 盯什么 + 关联破的条件 + **毕业线（踩到什么→升 CUT）**  • 状态 |

**不回写**：纯 HOLD、噪音、与上次无变化的观察项（避免台账被每日噪音淹没）。

**写法**：在目标持仓「复盘备注」**最前面**加一条 `YYYY-MM-DD 类型：…`，旧记录原样保留；观察项行首加 🔭 便于下次扫描；某观察项熬成 CUT 时，把它改判并注明「→ 已转 CUT」。

### ⑥ 预备追问（caca 的真实节奏：分析 → 追问）
输出后默认待命这三个，不主动展开：
- 🔬 **核数**：🔭逼近 / 🔴已破候选已在 ③.5 自动追一手；这里待命的是 caca 想再核的其余持仓 → 去 SEC EDGAR 拉一手 8-K / EX-99.1（别只信 Yahoo 标题）。子流程见下。
- 📥 **落库**：durable 项已自动回写；其余等 caca 点名再写。
- 🔎 **深挖**：某条信号读到 Item N / 一手原文为止。

## 核数子流程（一手优先）
**何时触发**：① 持仓财报日；② ③.5 触发的任何 🔭 逼近 / 🔴 已破候选（不再限于财报日）。
1. 打开该 8-K 的 EDGAR filing **index 页**，拿文档列表（8-K 正文 + `EX-99.1` press release）。
2. `connections.web.loadPage` 读 `EX-99.1` 拿真实数字（营收 / EPS / 指引 / 现金流）。
3. 对照该持仓「破的条件」给结论，按 ⑤ 回写复盘备注。

SEC 个体 XML / 单页常 500 / 404 / 504 → 退到 index 页 + 搜索页拿间接证据（reporter 身份 / filing 频率 / period of report）。

## 硬红线（继承 v2 · 违反就重写）
- ❌ 给 HOLD / ADD / CUT / PASS 之外的第 5 种判决（「密切关注」/「建议减仓」/「设止损位」）——逼近态只进 🔭 观察项 + 台账，**不进判决**
- ❌ 给具体股数 / 价位 / 时点
- ❌ 给浮盈「加止损」建议——价值投资不止损，赢家继续跑
- ❌ 重亏（如 GDXU）直接建议止损——先问 thesis 是否还成立
- ❌ 替 caca 拍板（「我建议你卖出 XX」）
- ❌ 把短线指标（trailing stop / 浮盈 % / 1d 涨跌）当判决依据
- ❌ 凑判决（CUT / ADD 不该有就老实写全 HOLD）
- ❌ 凭空给 ticker 写 thesis——没写就老实 PASS
- ❌ 鼓励 / 焦虑话术 / 预测涨跌 / 无源表述（「市场预期」/「据传」/「我觉得」）
- ❌ 整段贴简报正文（caca 已看过 raw）
- ❌ 把复盘备注写成每日噪音流水——只回写 durable
- ❌ 立「我在盯」的空观察项——观察项必须带可证伪的**毕业线**（踩到什么具体指标 → 升 CUT）；写不出毕业线就当噪音丢掉或直接出判决（v4 第三刀）
- ❌ 日频 HOLD 假装成 thesis 测过了——日频只抓离散事件 + 扫价值线 + 轮值深挖 1 只，系统性重测留给季频复盘（v4 第一刀）

## 数据脏 / 缺失

| 情况 | 处理 |
|---|---|
| 台账空（任何 ticker 都没写过） | 让 caca 先去台账写 ≥5 只持仓的 thesis，不在零 thesis 下做判决 |
| 简报有 ticker 但台账无此行 | 视为 Status=待补，输出 PASS + 提醒添加 |
| pl_pct 异常（QQQ +325% 富途 SIM 残留） | 标「⚠️ 数据异常」但不影响判决（thesis 判决不依赖 pl_pct） |
| Generated At > 2h 前 | 标「⚠️ 快照过期，仅供参考」 |
| 数据库今日无行 | 说明可能原因（cron 未触发 / Actions 失败 / 美股节假日）+ 给排查方向，不瞎编 |

## 决策辅助 = 不下决定
caca 复盘原话：**「数据没问题但不推动决策」是真实失败模式**。本 skill 的价值 = 让 caca 5 秒知道：① 今天有没有 thesis 破？② 有没有跌进加仓区？③ 哪些逼近态在动？④ 其余都不用动？四问答完关页面。
