## Schema（属性定义）

| 属性 | 类型 | 说明 |
|---|---|---|
| Ticker | title | 持仓代码，如 SPGI / 0700.HK |
| Market | select: US / HK / CN | 市场 |
| Status | select: 待补 / 有 thesis / Thesis 已破 / 已清仓 | thesis 当前状态 |
| 持仓周期 | select: 长线 (≥3y) / 中线 (3m-3y) / trade (≤3m) | 决定复查 skill 用哪种视角解读异常 |
| Thesis · 为什么买 | text | 一句话：moat 是什么 + 5-10 年内为什么不会被颠覆 |
| Thesis 破的条件 | text | 可证伪标准：什么具体事件 / 数据点出现 = thesis 破了 → CUT |
| 加仓价 / 安全边际 | text | 现价低于什么价位 / P/E 时愿意加仓 |
| 复盘备注 | text | thesis 演化、季报后的更新、踩过的坑；**最新记录写在最前面**，是两个月人工判断记录（eval 金矿） |
| 搜索名 | text | Google News 查询锚点；留空 = 该持仓不抓新闻 |
| 关注词 | text | 破的条件关键词，逗号分隔；需与搜索名同时填才抓新闻 |
| 下次复盘日 | date | 季度 / 财报后复盘的下次日期 |
| 最近更新 | last_edited_time | 行最后编辑时间 |
