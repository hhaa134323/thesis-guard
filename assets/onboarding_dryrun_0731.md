# 录入演练 transcript · 2026-07-31

背景：AI 演产品（持仓核对助手），caca 演用户。验证「对话 → 结构化 thesis 卡」录入流程。
产出：录入 Agent 行为 spec + 首批 eval 用例。

## 第 1 轮
产品：你好，我是你的持仓核对助手。先从一只票开始：你现在持有的美股里随便说一只——它是什么？你当初为什么买它？
用户：HSBC，因为按照年来看，它的股价表现稳健上升的形状

## 第 2 轮（追问：可判定性 + 图形型 thesis 翻译）
产品：好，HSBC 记下了。但「稳健上升的形状」这句我要追问——它决定我以后每天替你盯什么：
1. 你信的是图形本身，还是图形背后的公司？如果 HSBC 往后继续每年稳涨，你觉得主要靠什么撑着？比如它一直大手笔派息回购？亚洲业务在涨？利率环境？还是你说不上来，就是走势看着稳？
2. 什么情况出现，你会觉得「形状破了，当初的理由不成立」？说具体一点：是跌多少（比如从高点回撤 20%）？跌多久（比如连续两个季度往下）？还是发生某件事（比如突然砍派息）？
用户：1、公司  2、无法确定，那得想想什么会让这家公司变得让人无法信任

## 第 3 轮（候选菜单：假设与破条件镜像，选一次填两槽）
产品：「信公司」+「说不上什么算破」——大多数人就卡在这。这一步我来给候选，你挑就行。
A. 你信的是什么？（可多选、可补充）
- A1 真金白银的股东回报：高分红 + 持续回购
- A2 亚洲业务（香港、内地）利润基本盘稳
- A3 资本充足，监管不找大麻烦
- A4 管理层战略清晰，重组聚焦见效
B. 破的条件（勾 1–5 条，每条我每天都能从公告里核对）
- B1 宣布削减或暂停派息
- B2 回购规模大幅缩水或叫停
- B3 核心资本充足率（CET1）跌破管理层自己定的目标线
- B4 信贷成本暴增（尤其跟中国商业地产相关的）
- B5 CEO / CFO 突然换人
- B6 监管开出大额罚单
另外坦白一条限制：你最初说的「形状破了」是价格条件，我目前不接行情数据，没法每天自动盯——可以记成「人工自查项」，每月提醒你自己看一眼年线。
A 选几项？B 勾哪几条？
用户：1、A4  2、B6？

## 第 4 轮（确认卡：两层条件结构）
产品：抓到一件事：你信的是 A4（管理层战略），勾的却是 B6（监管罚单）——这两个不是一对。默认处理：破的条件分两层，A4 的「镜像条件」我替你补上，B6 放进每只持仓默认带的「通用红线」。B6 那个问号我也看到了——意思是：如果 HSBC 被监管开出大额罚单（比如当年 19 亿美元级别的洗钱罚单），不管战略多好，信任都清零。为让机器能核对，定成可判定的：单次罚款 ≥ 5000 万美元，可改。

确认卡 · HSBC（汇丰控股）
| 字段 | 内容 |
|---|---|
| 买入逻辑 | 年线看股价稳健上升（你的原话） |
| 关键假设 | 管理层战略清晰，重组聚焦见效 |
| 破的条件 ① · 镜像（系统补） | 宣布战略转向、重组叫停，或亚洲核心资产被剥离 |
| 破的条件 ② · 镜像（系统补） | CEO / CFO 突然离职 |
| 破的条件 ③ · 通用红线（用户勾） | 监管大额罚单，单次 ≥ 5000 万美元（可调） |
| 人工自查项 | 价格「形状」：每月 1 号提醒自己看一眼年线（系统不接行情） |

每天扫 HSBC 的 SEC 申报（6-K / 20-F）和头条新闻，命中任何一条就邮件推送，附原文链接。判断权在你。改哪条？还是说「确认」？
用户：确认。大多数情况下不会触发对吗

## 第 5 轮（静默日设计）
产品：对，这正是设计意图。破的条件按定义是「小概率、高重要性」事件——三天两头触发说明条件定错了。但没触发不等于没消息：
- 命中条件 → 当天单独发邮件，写明命中哪条，附公告原文链接
- 没命中 → 不单独打扰，每日简报一行带过：「HSBC：3 条条件均未触发（今日 2 条 6-K 已核）」
- 下跌难受的日子，你要的就是那行「均未触发」——坏的是价格，不是当初的理由。判断始终是你的。

## 演练产出的设计发现（进 PRD）
1. 两层条件结构：镜像条件（按假设自动补）+ 通用红线默认包（罚单/高管突变/财报重述，阈值可判定、可调）
2. 「无法确定」是常态 → 给候选菜单；假设与破条件镜像，选一次填两槽
3. 菜单有建议偏差风险：用户可能从菜单挑而非自发说 → W3 专项观察「选 vs 想」比例
4. 每条条件需附真实历史事件示例（用户对条件含义会不确定，如「B6？」）
5. 图形型 thesis → 人工自查项：不接行情，也要给用户原始理由一个安放处
6. 静默日推送策略：触发才单发，无事合并进每日简报
7. FPI 标的（HSBC 这类 20-F/6-K 申报方）主披露渠道是 6-K，不得沿用本土公司的 6-K 降级规则
8. 耗时 6 轮约 6 分钟，目标 3 分钟；压缩点：A/B 两问合一屏
